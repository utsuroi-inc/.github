# AIグループコーチング — サービス概要

> 出典：[公式案内ページ](https://utsuroi-inc.jp/coaching)（2026年10月24日確認）
>
> 区分：**公開情報の整理**。契約条件・参加料金の確定書ではありません。
>
> 運営：株式会社うつろい／進行：竹添 裕馬

## 1. 一言でいうと

**中小企業の経営者・役員3〜4名が、各自の実際の仕事で生成AIを試し、毎週の対話と振り返りを通じて「続ける・変える・やめる」を判断する、3か月・全12回の少人数共同実践プログラム。**

AIの知識を増やすことだけが目的ではありません。AIを使って何が起きたかを観察し、仕事の流れと自分の判断に変化を残すことを目指します。

## 2. 誰の、どんな課題に応えるか

**対象**

- 中小企業の経営者・役員
- AIに詳しいかどうかより、「今週から実務で試す」意思がある人
- 毎週60分の参加枠と、普段の仕事でAIを試す機会を確保できる人
- 成功だけでなく失敗・詰まりも共有でき、他者の事例を自分の仕事に翻訳して考えられる人

**主な課題**

- AIについて学んだが、日常業務は変わっていない
- 忙しいとAI利用が止まり、継続が意志頼みになっている
- 一般的な活用例から、自社の業務にどう落とし込むか分からない
- 実験の成功・失敗を相談し、次を決める相手がいない

講義の受講だけを求める人、実装を丸ごと外注したい人、毎週の実践時間を確保できない人、特定ツールの短期操作習得を求める人には、別の支援方法が合う場合があります。

## 4. サービスの中心となる実践サイクル

1. **問いを絞る**：発信、提案書、調査、顧客対応など、今変えたい仕事を具体化する。
2. **仕事で試す**：AIの担当、人が確認する範囲、必要な品質を実務で検証する。
3. **事実を見る**：時間・品質・相手の反応・止まった理由を振り返る。
4. **次を決める**：結果が良くても悪くても、続ける・変える・やめるを選び、翌週の一歩を決める。

毎週のセッション前に、約10分を目安に次の項目を振り返りシートへ記入します。

1. めざす姿：今、何を変えたいか
2. 今週の計画：何を試そうとしたか
3. 行動と結果：実際に何が起きたか
4. 気づき・学び：見方や前提がどう変わったか
5. 来週の一歩：普段の仕事のどこで試すか

### 60分の基本進行

| 時間 | 内容 |
| --- | --- |
| 0〜5分 | 瞑想・チェックイン |
| 5〜45分 | 参加者A〜Dが順番に、各10分程度、実践内容を共有して感想を受け取る（4名の場合の例） |
| 45〜60分 | 今週の締め・次の実践の確認 |

授業を受けて終わるのではなく、**日常業務 → 実験 → 記録 → 他者との対話 → 判断 → 次週の業務**を往復する設計です。

## 5. 3か月後に何を残すか

目指す状態は「AI活用を完成させる」ことではなく、改善する業務と使わない条件を自分で見極め、**次の90日を選べる**ことです。

参加者自身に残す判断資産は、公式ページでは次のように示されています。

- 最初の問いと、3か月で変化した問い
- 実際に試したこと、起きた事実
- 対象業務と見直した業務フロー
- プロンプト、人の確認箇所、品質基準
- 続ける・変える・やめると決めたこと
- 次の90日で実行すること

**成果保証ではありません。** 試行がうまくいかなくても、使わない条件や次の判断が明確になれば学びとして扱います。

## 6. 参加・終了の流れ

1. 30分の個別面談
2. 双方で目的・相性・日程を確認
3. 正式申込み
4. 3か月の共同実践（週次シートと対話）
5. 終了後1on1で実践・判断・次の90日を棚卸し

終了後は、(A)卒業・自走、(B)次期参加または月次グループ、(C)AIコーチ、(D)法人向けAI導入・業務改善、(E)グループ形式の運営を担う、といった選択肢があります。**継続しないことも正式な選択肢**です。

## 7. 他サービスとの位置づけ

| 支援形態 | 主眼 | このサービスとの違い |
| --- | --- | --- |
| AI研修・セミナー | 知識・共通理解 | グループコーチングは各自の業務実験と週次レビューを主にする |
| AIコーチ（個別支援） | 1人の実務を継続的に改善 | グループは3〜4人が相互の実践から問いと判断を更新する、独立した公開プログラム |
| 法人向けAI導入・業務改善 | 事業・部署の業務実装と定着 | 企業内プログラムは目的やデータ管理を分け、個人の工夫をチームの型に変える |

同じ「AIコーチング」という語でも、**この公開グループは個別AI家庭教師／AIバディの契約条件をそのまま適用する商品ではありません**。公開グループのサービス説明と個別・法人向けの商品設計を混同しないでください。

## 8. 情報の取り扱いと参加ルール

- 参加者は顧客・社内情報の取扱ルールを守り、AIへ入力してよい情報かを確認する。
- 氏名・発言・成果物を外部で公開する場合は、**本人から別途許可を取る**。
- 企業内版は公開グループとは別に設計し、アンケートを人事考課・査定へ流用しない。
- 公開ページは企業内版の参加者向けアンケートに「株式会社うつろい」の表示を入れない方針を記載している。
- 欠席時は週次シートの共有を参加扱いとし、翌週に拾う。ただし毎週の60分枠を確保することが原則。
- 参加前に[参加ガイドライン（PDF）](https://utsuroi-inc.jp/docs/participation-guideline-20260914-v2.1.pdf)を確認する。
