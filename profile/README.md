# 株式会社うつろい / Utsuroi Inc.

株式会社うつろいは、大阪を拠点に、
AIやソフトウェアを使いながら、
会社の仕事のやり方を今の会社に合う形へつくり直す会社です。

AIを導入すること自体を目的にせず、
業務改善、新規事業、ナレッジ活用、AIエージェントなどを
小さく試し、実装し、組織に残る形まで伴走します。

🌐 https://utsuroi-inc.jp/

## What we do

### AI実証研究
まだ答えのないテーマを小さく実装し、
現場や市場で成果が出るか検証します。

### AIバディ
経営者やAI推進担当者とともに、
日々の仕事を題材にAI活用を進めます。

### AI導入・内製化
研修・実装・業務改善を組み合わせ、
社員自身がAI活用を続けられる状態をつくります。

### AIグループコーチング（公開プログラム）
経営者・役員3〜4名が、3か月・全12回にわたって
実際の仕事でAIを試し、毎週の振り返りと対話から次の判断をつくります。
