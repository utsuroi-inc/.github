# 標準セキュリティテスト（本番ではなく許諾済みステージングで実施）

| ID | 対象 | ケース | 合格条件 |
| --- | --- | --- | --- |
| AUTH-01 | 匿名ユーザー | 非公開画面とAPIを直接開く | 認証が要求されデータを返さない |
| AUTH-02 | 一般ユーザー | 管理者APIを呼ぶ | 403等で拒否 |
| AUTH-03 | ユーザーA/B | AのIDを指定してBが閲覧する | BはAのデータを取得できない |
| AUTH-04 | ユーザーA/B | BがAのデータを更新・削除する | 更新・削除されない |
| AUTH-05 | セッション | ログアウト・失効後の操作 | 再利用できない |
| INP-01 | 入力値 | 特殊文字、過長値、不正な型 | 検証で拒否または安全に処理 |
| SEC-01 | Secrets | ビルド成果物・Git履歴・ログを点検 | 本物の秘密値が存在しない |
| SEC-02 | 依存関係 | ロックファイルをスキャン | 未解決の重大既知脆弱性なし |
| DATA-01 | 個人情報 | 権限外の検索・一覧・エクスポート | 顧客・利用者間で情報が混ざらない |
| DATA-02 | バックアップ | 復旧手順を安全なテストデータで確認 | 指定した時間内に復旧可能 |
| CF-01 | Cloudflare Access | 未認証でカスタムドメインへアクセス | 拒否 |
| CF-02 | Cloudflare Access | 別の公開URL・プレビュー・APIにアクセス | 想定外の経路から到達できない |
| CF-03 | Cloudflare Access | 許可されたユーザーでアクセス | 必要な機能のみ利用可能 |
| DEP-01 | GitHub | テスト失敗PRのmainマージを試す | ブロックされる |
| DEP-02 | デプロイ | 未承認SHAの本番反映を試みる | ブロックされる |
| DEP-03 | ロールバック | 承認済みの前バージョンへ戻す | 手順どおり復旧できる |

各テストには実行者、日時、環境、対象SHA、結果、証跡URLを残す。匿名・別ユーザーのテストは**所有・許諾された環境とテスト用アカウントのみ**で行う。
