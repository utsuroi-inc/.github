# 各アプリのAGENTS.mdに追記する共通セキュリティルール

この文書はコピー用の追記テンプレート。既存AGENTS.mdがあれば上書きせず統合し、`CLAUDE.md`は`@AGENTS.md`を参照する。

## 必須ルール

1. 作業前に、リスク区分・データの種類・環境・公開可否を確認する。
2. Codex/Claude Codeは機能実装だけでなく、認証・認可・入力検証・秘密情報・依存関係・ログを必ず検討する。
3. デモのための認証回避・ダミー権限・固定パスワードを本番の経路へ入れない。
4. APIはサーバー側でユーザー・テナント・対象データごとの権限を検証する。
5. 本番秘密情報、個人・顧客データ、DBダンプをコミット、AIチャットに貼り付け、未承認の第三者サービスへ送信しない。
6. 実データを使うテスト、侵入的スキャン、公開・権限変更、費用発生、外部送信は実行前に人の明示承認を得る。
7. PRには目的、影響、テスト、セキュリティ確認、未解決事項、戻し方を記載する。
8. `main`への直接push、CI回避、公開状態の無断変更は行わない。
9. 検査エラー・スキップ・未実施を成功に読み替えない。問題が残れば公開不可と報告する。
10. 完了時には対象SHA、検査結果、残余リスクを報告する。AI自身は公開承認者にならない。

## 各アプリで追記する事項

- 技術スタック、`lint/typecheck/test/build`コマンド
- ユーザー種別・データ別の権限境界
- テスト用データ・環境URL（秘密値は記載しない）
- GitHubの必須チェック名とデプロイ経路
- Cloudflare Accessの保護対象と本番の運用責任者

本書は`utsuroi-inc/.github`の`SECURE_DEVELOPMENT.md`と`RELEASE_GATES.md`の下位規則とする。
